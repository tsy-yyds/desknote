          悬浮便签 DeskNote v1.0  使用说明
═══════════════════════════════════════════════════════

【软件是什么】
一个常驻桌面、开机自启的悬浮便签软件。便签像便利贴一样
贴在屏幕上，随时记录、随时查看，关掉后内容自动保存。

───────────────────────────────────────────────
【快速开始】
方式一（推荐，无需任何环境）：
  1. 双击「打包exe.bat」，等待 1~3 分钟，自动打包成
     dist\悬浮便签.exe
  2. 把「悬浮便签.exe」发送到桌面快捷方式，双击运行

方式二（当前直接用）：
  双击「启动便签.bat」，便签立即出现在屏幕中央。
  （要求电脑已装 Python 3.14，本机已满足）

───────────────────────────────────────────────
【便签窗口按钮】  （右上角一排小按钮）
  钉  = 置顶开关：让便签永远浮在最上层
  藏  = 贴边隐藏开关：拖到屏幕边缘自动收起，
        鼠标移到屏幕边缘自动弹出
  透  = 透明度：6 档可调（60%~100%）
  色  = 便签颜色：黄 / 绿 / 粉 / 蓝 / 紫 / 橙
  ＋  = 新建一张便签
  —  = 隐藏到托盘（不退出，任务栏右侧找小图标）
  ×  = 删除这张便签（删完会自动补一张空白便签）

  在标题栏上点右键，也能打开同样的功能菜单。

【其他操作】
  · 拖动标题栏移动便签，拖动右下角 ⤡ 调整大小
  · 在便签里直接打字即可，停顿一秒自动保存

【字体自定义】（标题栏右键菜单 →「字体设置…」）
  · 字体：20 种常见字体任选（微软雅黑 / 宋体 / 黑体 / 楷体 /
    仿宋 / 等线 / 隶书 / 幼圆 / Consolas / Arial 等）
  · 字号：10 ~ 40 可调（滑块拖动，实时预览）
  · 文字颜色：12 种预设色板 + 「自定义取色…」打开系统取色器
    自由调色；点「恢复主题色」回到便签纸默认颜色
  · 设置实时生效，每张便签独立保存、重启不丢

───────────────────────────────────────────────
【系统托盘】  （任务栏右下角黄色小便签图标）
  左键单击：暂时无动作（防止误触）
  右键菜单：
    · 新建便签
    · 显示全部便签
    · 隐藏全部便签
    · 开机自启  ← 勾选后开机自动静默运行（写注册表）
    · 退出      ← 真正退出程序

  便签点「—」隐藏后，就从托盘菜单「显示全部便签」找回。

───────────────────────────────────────────────
【开机自启说明】
  在托盘菜单勾选「开机自启」即可，无需其他设置。
  注册表位置：HKCU\Software\Microsoft\Windows\CurrentVersion\Run
  开机后自动静默运行，无黑窗口、无弹窗，便签直接出现在桌面。

  注意：如果你用「启动便签.bat」方式，开机自启默认调用
  pythonw.exe（已内置于 bat 对应路径，无需担心）。
  若打包成 exe 后勾选自启，则开机直接运行 exe，更快更稳。

───────────────────────────────────────────────
【数据保存位置】
  便签内容、位置、颜色全部自动保存，位置跟着程序走：
  · 用 exe 方式：保存在 exe 旁边的 data\notes.json
    （即 dist\data\notes.json）
  · 用 bat 方式：保存在桌面工程文件夹的 data\notes.json
  删除该文件 = 清空所有便签。想备份直接复制它即可。
  重新打包 exe 不会影响已保存的数据（data 文件夹不会被清掉）。

───────────────────────────────────────────────
【常见问题】
  Q：开机自启勾选了，但开机没弹便签？
  A：开机自启是静默运行，便签会出现在上次关闭时的位置。
     如果桌面太满没看到，点托盘图标右键「显示全部便签」。

  Q：便签找不到了？
  A：先看托盘有没有黄色小图标，右键菜单点「显示全部便签」；
     若整个托盘图标也没了，双击「启动便签.bat」重新拉起。

  Q：重复启动了会开多个吗？
  A：不会。程序有单实例保护，第二次启动只会把已运行的
     便签全部唤出。
