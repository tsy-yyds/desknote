# 🗒 悬浮便签 DeskNote v1.0

一个常驻桌面、开机自启的悬浮便签软件。便签像便利贴一样贴在屏幕上，随时记录、随时查看，关掉后内容自动保存。

## ✨ 功能

- 📌 **置顶**：便签永远浮在最上层
- 🧲 **贴边隐藏**：拖到屏幕边缘自动收起，鼠标移过去自动弹出
- 🔍 **透明度**：6 档可调（60% ~ 100%）
- 🎨 **便签颜色**：黄 / 绿 / 粉 / 蓝 / 紫 / 橙
- ➕ **多便签**：可新建多张，各自独立记录
- 💾 **自动保存**：停顿一秒自动保存，关闭后内容不丢
- 🔤 **字体自定义**：20 种字体、字号 10~40 可调
- 🖥 **系统托盘**：隐藏到托盘常驻，不占任务栏

## 🚀 快速开始

| 方式 | 操作 |
|---|---|
| 方式一（推荐，免环境） | 双击 `打包exe.bat` → 生成 `dist\悬浮便签.exe` → 双击运行 |
| 方式二（需 Python 3.14） | 双击 `启动便签.bat` 直接运行 |

下载现成的安装包：见右侧 **Releases** → `悬浮便签.exe`（单文件，双击即用）。

## 📂 文件说明

- `desknote.py` — 主程序源码
- `悬浮便签.spec` — PyInstaller 打包配置
- `使用说明.txt` — 完整使用说明
- `icon.ico` — 程序图标

## 🛠 技术

Python 3.14 + tkinter，PyInstaller 打包单文件 exe。
